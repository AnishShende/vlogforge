# Module: docs

## 📌 Purpose & Responsibility
- Stores **example and reference data files** generated by the VlogForge pipeline.
- Contains historical EGT (Editorial Ground Truth) JSON dumps, EDL (Edit Decision List) JSON outputs, and raw transcript JSON files.
- Used primarily by developers to understand the structure of the pipeline's internal data formats without needing to run a full rendering job.
- Provides test fixtures and examples that can be used by diagnostic scripts in the `backend/` root (like `dump_egt.py`).

## 🔄 Integration & Data Flow
- **Inputs**: JSON structures exported manually from completed backend jobs.
- **Outputs**: Static reference data consumed by developers and debug scripts.
- **Interactions**: These files are entirely static. `backend/dump_egt.py` reads from this folder to print human-readable tables of the EGT data.

## 📂 Code Symbols & Key Files
- **[cf42_egt.json](docs/cf42_egt.json)**: A complete reference EGTDocument containing populated `EGTSegment` items (with classification, quality scores, tags, and transcripts).
- **[cf42_edl.json](docs/cf42_edl.json)**: A reference Edit Decision List generated from the corresponding EGT.
- **[latest_egt_output.json](docs/latest_egt_output.json)**: Sample of the most recent EGT format output by the perception pipeline.
- **[phase1_edl_test.json](docs/phase1_edl_test.json)**: Sample EDL from the Phase 1 reasoning pipeline.
- **[egt_summary.txt](docs/egt_summary.txt)**: Text summary output of an EGT diagnostic run.
